# Contributing to YACB

Thanks for taking an interest in YACB.

## Development

1. Fork and clone the repo
2. Install dependencies: `npm install`
3. Copy env: `cp .env.example .env.local`
4. Start LM Studio with a model loaded and the local server running
5. Run the app: `npm run dev`

## Guidelines

- Keep the UI minimal — black and white, no heavy chrome
- Prefer small, focused pull requests
- Do not commit secrets (`.env.local`, API keys, credentials)
- Run `npm run lint` and `npm run build` before opening a PR

## Pull requests

Describe what changed and why. Link any related issue.
